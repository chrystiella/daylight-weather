# Daylight Weather

A location-based weather dashboard built with React, TypeScript, and Vite.

## Run locally

1. Install Node.js if it is not already installed.
2. In a terminal opened in this folder, run:

   ```powershell
   npm.cmd install
   npm.cmd run dev
   ```

3. Open the local URL printed by Vite.

Use **Use my location** to request browser location access, or search for a city or ZIP code. Fahrenheit is the default; the unit toggle switches to Celsius and remembers the selection.

Weather forecasts and city search use the Open-Meteo Forecast and Geocoding APIs. No account, API key, or backend is required.
